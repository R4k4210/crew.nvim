crew.nvim · mockup within Neovim limits

Agents as workspaces, not splits

Each agent instance lives in its own tab. Pills show only the slot and a state icon, in bufferline and in lualine. Names, profiles and usage live in the picker, where there is room for them.

jump editor ⇄ last agent pick instance new from profile name this instance close

Two pickers with no file preview

Crew opens its own snacks pickers with layout = { preview = false }, so your global layout keeps its preview for files and grep. Without snacks it falls back to vim.ui.select.

␣an lists profiles from opts.agents (claude, claude-work, codex, as many as you define). ␣ap lists open instances in aligned columns: slot, profile, name, then context, 5 hour and weekly usage with their resets.

Naming an instance

␣ai opens a one line input for the current instance. The name only shows in the picker and the agent tab header, never in the pills, so it can be as long as you want.

Usage cells show – when an agent does not report them yet, like a Claude session before its first answer or a CLI such as codex that sends no limits.

What Neovim can draw

Everything here is a grid of cells with a color, a background and bold. Floats get rounded borders, but statusline pills are flat blocks, and the ask pill blinks by swapping its highlight on a timer.
